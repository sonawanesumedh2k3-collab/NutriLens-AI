PROJECT METHODOLOGY

From raw food data to AI-powered analysis.

This page presents the complete development journey of NutriLens AI — from dataset preparation and exploratory analysis to machine learning, deployment and database integration.

PROBLEM DEFINITION

Why NutriLens AI?

Packaged food products contain nutritional information that can be difficult to interpret quickly. Consumers may see values such as calories, sugar, sodium, fat, protein and fiber without having a simple way to understand the overall nutritional profile.

NutriLens AI addresses this problem by processing nutritional information, generating a project-defined health score and using machine learning to classify the product into a nutritional category.

PROJECT OBJECTIVES

What the system aims to achieve

  • Analyze nutritional information of packaged food.
  • Normalize nutritional values to a common per-100g basis.
  • Generate a consistent project-defined health score.
  • Train and compare multiple machine learning models.
  • Deploy the selected model through a Flask web application.
  • Store analysis results using MySQL for future reference.
TECHNICAL METHODOLOGY

From Nutrition Values to ML Features

Raw nutritional values are transformed into standardized features before they are passed to the machine learning model.

01

Per-100g Normalization

Products can have different serving sizes, so direct comparison of serving-based values is not reliable. The nutritional values are therefore converted to a common per-100g basis.

Per 100g Value (Nutrient Value ÷ Serving Size) × 100
Calories Sugar Saturated Fat Sodium Protein Dietary Fiber
02

Health Score Generation

A project-defined scoring framework converts the nutritional features into a numerical health score. Higher negative nutritional values increase the score, while protein and fiber contribute positive points.

Negative Factors Calories + Sugar + Saturated Fat + Sodium
Positive Factors Protein + Dietary Fiber
03

Health Category

The calculated score is converted into three project-defined categories used as the target variable for machine learning.

Healthy Score ≤ 5
Moderate Score 6–18
Unhealthy Score > 18
04

ML Input Features

Six normalized nutritional features are selected as inputs for the machine learning models.

Calories / 100g
Sugar / 100g
Saturated Fat / 100g
Sodium / 100g
Protein / 100g
Dietary Fiber / 100g
Methodological Note

The health score and categories are defined specifically for this project for analytical and educational purposes. They should not be interpreted as an official FSSAI classification or medical recommendation.

LIMITATIONS & FUTURE SCOPE

Current Scope and Future Improvements

The current NutriLens AI implementation focuses on nutritional analysis, machine learning classification, web deployment and database-based history management.

⚠

Current Limitations

  • The health score is a project-defined scoring framework and is not an official FSSAI classification.
  • The model uses six nutritional features and does not currently analyze the complete ingredient list.
  • The target categories are generated using the project's scoring rules.
  • Model accuracy is evaluated using the available packaged-food dataset and held-out test data.
  • The system is designed for nutritional analysis and should not be treated as medical advice.
🚀

Future Scope

  • Add ingredient-list analysis using Natural Language Processing.
  • Detect additives, allergens and potentially concerning ingredients.
  • Integrate OCR to extract nutrition information directly from food packaging images.
  • Expand the dataset with more Indian packaged food products and categories.
  • Add personalized recommendations based on user-selected nutritional preferences.
  • Explore additional machine learning models and improved evaluation techniques.
